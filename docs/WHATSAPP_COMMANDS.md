# פקודות WhatsApp

## רשימת פקודות

| פקודה | תיאור |
|-------|-------|
| `/stats` או `/סטטיסטיקות` | סטטיסטיקות החודש - הכנסות, פגישות, שעות |
| `/today` או `/היום` | רשימת פגישות היום |
| `/week` או `/שבוע` | רשימת פגישות השבוע |
| `/add [פרטים]` | הוספת פגישה חדשה |
| `/help` או `/עזרה` | הצגת רשימת פקודות |

## הוספת פגישה

אפשר להוסיף פגישה בשתי דרכים:

### דרך 1: פקודת /add

```
/add מחר 14:00 שעתיים חברת ABC סדנה 1000 שקל
```

### דרך 2: הודעה חופשית

פשוט שלח את פרטי הפגישה כטקסט:

```
מחר בשעה 14:00, שעתיים, חברת ABC, סדנה, 1000 שקל
```

המערכת תשתמש ב-AI כדי לפרש את ההודעה ולהוסיף את הפגישה.

## דוגמאות הודעות

### סטטיסטיקות
```
משתמש: /stats
בוט: 📊 סטטיסטיקות החודש:
     💰 הכנסה כוללת: ₪12,500
     ✅ שולם: ₪8,000
     ⏳ ממתין: ₪4,500
     📅 פגישות: 15
     ⏱️ שעות: 28.5
```

### פגישות היום
```
משתמש: /today
בוט: 📅 פגישות היום (01/02/2026):
     1. חברה X - 10:00 (2 שעות) - סדנה
     2. לקוח פרטי - 15:00 (1 שעות) - ייעוץ
```

### הוספת פגישה
```
משתמש: /add ביום שלישי 19:00 שעתיים לקוח חדש הרצאה 800
בוט: ✅ נוספה פגישה!
     חברה X - 02/02/2026 בשעה 14:00
```
